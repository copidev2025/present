# Responsive Image Page

This project is a simple responsive HTML web page that features a main image centered on the page. The image adjusts to different screen sizes, ensuring a good user experience across devices.

## Project Structure

```
responsive-image-page
├── src
│   ├── index.html        # The main HTML file containing the structure of the page
│   └── styles
│       └── style.css     # The CSS file for styling the HTML page
└── README.md             # Documentation for the project
```

## Getting Started

To set up this project locally, follow these steps:

1. **Clone the repository** (if applicable):
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd responsive-image-page
   ```

3. **Open the `src/index.html` file** in your web browser to view the page.

## Usage

The main image is located in the `src/index.html` file. You can replace the image source in the HTML file to use your own image. The CSS in `src/styles/style.css` ensures that the image is centered and responsive.
